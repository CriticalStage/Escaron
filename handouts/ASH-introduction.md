# 灰葦村への同行依頼

ダリア・モーンは、離れて暮らす故郷へ戻り、父の墓と家財を確かめたい。村はベルフォードから西へ、堤道と湿地を通って41km。途中の渡し小屋に一泊し、翌朝村へ入る。

報酬は一行へ120GP。墓と家の現状確認に60GP、安全な帰還と家財の回収に60GP。家財が失われていても、十分に捜した場所と状況が分かれば支払う。手付は30GP。

案内人と食料、往復の渡し小屋の寝床は手配済み。ダリアは、古い家の間取りを旅の荷にしまった。
