# オルデン橋の点検依頼

北街道14km先のオルデン橋で、荷車が足止めされている。橋脚の点検へ入った職人リオ・ケストも、昨日から戻らない。

市と公国は、一行へ救助・安否確認の報酬60GP、橋の取り付き部と排水の点検報告に60GPを用意した。即日開通や、通行料についての合意は支払条件ではない。必要なロープ、灯具、手道具、補修材は現地で貸してもらえる。

午前7時にベルフォードを出れば10時ごろ着く。夕方には上流の雨で水位が上がる予報。橋の地上には衛兵、作業員、足止めされた旅人たちが集まっている。
