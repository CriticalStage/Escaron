# 灯のともる港から

朝の鐘が鳴り響くと、ベルフォードの魚市場は活気に包まれる。塩魚の籠を担ぐ者、船荷の札を一枚ずつ改める商人、焼きたての麦パンを二つに割って湯気を吸い込む水夫。波止場の向こうには、海から突き出た巨大な石の橋脚群が、朝霧を突き破るように並んでいる。かつて世界を繋いでいた古代の遺構――その一つの天頂に、昨夜、新たな灯火がともされた。

あなたたちは、この港から未知の旅路へと漕ぎ出す冒険者だ。
長い旅を終えて帰ってきたときには、馴染みの酒場で席を詰めて温かいスープを分けてもらえるかもしれない。旅先で助けた職人が、この町に新しい工房を開いているかもしれない。手に入れた金貨で、自分たちの小さな船を買う相談を始める夜が来るかもしれない。

あるいは北へ伸びる石畳の街道を選べば、緑豊かな麦畑と深い森、古風な石造りの城下町、のどかな村の水車が待っている。宿の掲示板で護衛の仕事を探し、古びた地下室を調べ、夕食の鐘が鳴るまでに村へ戻ってくる――そんな素朴で手触りのある冒険から始めてもよい。

旅の先には失われた世界の面影があり、帰ってきた港や宿場には、昨日までなかった新しい暮らしが息づいているだろう。

## CH-01-start この本で遊ぶ

本書『諸王冠と埋み火：クラウンズ・アンド・エンバーズ』は、1〜6レベルの冒険者たちが、港町ベルフォードや街道の宿場を足場に、未知の荒野や忘れ去られた遺跡へ挑む旅を紡ぐための世界設定である。
プレイヤーはそれぞれ一人の冒険者を担当し、ゲーム・マスター（GM）は土地と人々、立ちはだかる試練、そして世界の息遣いを受け持つ。

物語の結末はあらかじめ決まっているわけではない。崩れかけた石橋をどう渡るか、灯の消えた小島で誰の手を取るか――あなたたちの選んだ行動とサイコロの一振りが、この土地の明日を切り拓いていくのだ。

## CH-01-world 最初に知っている世界

世界の名は**エスカロン**。今はヴァルドラン暦842年、ヴァルダ内海を渡る帆影が再び増え始めた時代だ。

かつてこの海を取り囲み、「我らが海」と呼んで絶対の覇権を誇った**ヴァルドラン帝国**（古文書や学僧の雅語では**ヴァルドリオン**と呼ばれる）が崩壊したのは、147年前のことだ。帝国は内海西岸の軍道網と、南岸に広がる広大な穀倉平野を両輪として栄えたが、過酷な徴税に耐えかねた諸都市の離反と後継者争いによって自壊した。南岸平野の背後には、乾燥台地やステップ、未知の巨石遺構へと続く広大な**南方大陸**が連なっている。

そして63年前、内海を突如として**灰燼の大嵐（かいじんのおおあらし）**が襲った。東の外海へと抜ける狭い多重海峡が激浪と浅瀬の移動で塞がれ、内海は逃げ場を失った暴風と火山灰に数十年にわたって苛まれた。港や水路を失った人々は、内陸の安全な高台や山あいの谷間へと逃れていった。

海がようやく凪ぎ、失われた航路が戻り始めたのは18年前のことだ。今では、外海からの船や内陸からの荷車が、祖父母の故郷を目指す子や孫たちを港へと運んでくる。人々はこの希望に満ちた再興の時代を**〈帰還の時代〉**と呼ぶ。

帝国の瓦解後に並び立つ無数の王国、公国、自由市、商業同盟は、総称して**〈百冠（ひゃっかん）〉**と呼ばれる。帝国の古い法と騎士道を重んじる領主もいれば、市民の合意と商取引を何より重んじる町もある。北東の峻険なクローヴェン山系や、東方の海に浮かぶミズハ諸島には、帝国以前から受け継がれてきた独自の誇り高い歴史がある。

あなたたちが足を踏み入れる**ベルフォード**は、リーヴェン湾岸に位置する人口約9,000人の自由市だ。船の修繕、温かい食事、乾いた寝床、そして様々な仕事が揃い、傷ついた冒険者がいつでも安心して帰れる場所である。湾口にそびえる巨大な石造橋脚群はかつて海を渡っていた〈王冠橋〉の名残で、その頂には今、航路を照らす新しい灯台が築かれている。

神々の気配は、人々のささやかな暮らしの中にある。朝、パンを焼く炉に手を合わせる者。出港の朝、静かに海へ杯を注ぐ船頭。墓前に新しい野花を供えていく娘――。沖の灯台の火が暮れても灯らなければ、酒場の窓辺に自然と人が集まり、誰からともなく夜の海を見つめていた。

## CH-01-party 一緒に旅をする理由

冒険者たちの素性や目的は様々だ。出発する前に、全員で「なぜ今回は行動を共にするのか」を決めておこう。次の例を参考に、卓の好みに合わせて自由にアレンジしてよい。

- **共同の仕事**：港の窓口や街道の宿場で、同じ依頼書に連名で署名した。手に入れた報酬で、それぞれの次の一歩を踏み出したい。
- **帰郷の旅路**：仲間の一人の親族が、かつて捨てた沿岸の故郷へ戻ろうとしている。その道中を護衛するかわりに、道中で見つけた遺跡や財宝の手がかりを分かち合う。
- **失われた地図の探求**：古い海図や日誌の切れ端に、全員が共通の関心を持った。専門は異なるが、何が眠っているのかを共に確かめたい。
- **旅先での約束**：同じ船や隊商で嵐を潜り抜け、互いの腕前を認め合った。まず一つ、危険な仕事を共にやり遂げてから、今後の身の振り方を決める。

「金貨を稼ぎたい」者と「行方不明の灯守を救いたい」者が、同じ依頼の旗の下に集まることもある。仲間がピンチに陥ったとき、どんな頼み方なら手を貸すかを事前に話し合っておくと、初めて顔を合わせた旅人同士でも気持ちよく背中を預け合える。

## CH-01-origin あなたの出身とつながり

出身地、種族、信仰、これまでの歩みは、自由に組み合わせて決めることができる。同じエルフでも育った港町が違えば気風は異なり、同じ鍛冶場で修行したドワーフと人間がよく似た職人気質を持つこともある。

| 来歴の例 | 暮らしの記憶 | ベルフォードで結べる縁 |
|---|---|---|
| ベルフォード育ち | 帰港を告げる鐘の音で夕食の時間を知った | 港務官マレナに家族の仕事を知られている |
| オルセインの街道沿い | 麦畑の境界と宿場の料金を毎年話し合った | オルデン橋へ向かう護衛仲間に顔見知りがいる |
| サルヴェッタの港町 | 荷札の読み方と天秤の扱いを叩き込まれた | 南商館に親族か元の商売仲間がいる |
| クローヴェンの山あて | 冬の吹雪の前に道具と保存食を入念に点検した | 造船所へ特注の金具を届ける鍛冶屋と馴染み |
| ミズハの島育ち | 船底の貝殻を削り落とす日に近所総出で集まった | 船大工サヤと故郷の潮の歌や魚料理を語り合える |
| エルムウッドの森の集落 | 森へ入る吉日と、共同で薪を切り出す日を覚えた | ベルフォードへ干し薬草を売りに来る知人がいる |
| 大嵐で内陸へ逃れた家 | 見たこともない海辺の故郷の思い出話を聞いて育った | 帰還者の集まりで、家族の消息を知る人を探せる |

冒険者の種族は、ドラゴンボーン、ドワーフ、エルフ、ノーム、ゴライアス、ハーフリング、ヒューマン、オーク、ティーフリングから選べる。たとえば、ミズハの海風に育まれたドワーフの船大工、ベルフォードの帳場で働くオークの書記、南岸の商館からやってきたエルフの仲買人など、多彩な人物像を描ける。

選んだ背景（侍祭、犯罪者、賢者、兵士など）から得られる能力値、技能、特技、所持品を手がかりに、キャラクターがどんな暮らしを経て冒険へと足を踏み出したのかを土地に結びつけてみよう。

この町には様々な思惑が息づいている。船員の無事を願う潮路協会、自治と法を守る市民評議会、帳簿に目を光らせる商館、傷ついた者を無償で迎える修道院。どこかの組織に忠誠を誓う必要はない。酒場でたまたま隣り合った船員や、出立の朝に手を振ってくれる宿の主――そうした何気ない顔馴染みこそが、冒険者をこの町へと引き留める確かな絆になる。

1〜2レベルの冒険を通じて師匠や流派との縁を深め、3レベルに達したとき、キャラクターは自らの道を定めて固有のサブクラスを選択する。

## CH-01-example 話して、試して、先へ進む

テーブルの上でどんなやり取りが行われるのか、短い実例を見てみよう。

> **GM**：「荒波が打ち寄せる船着場に、小さな補給舟が一隻、傾いて打ち捨てられている。係留綱が一本千切れ、濡れた甲板の上に木箱が転がっているよ」
> 
> **プレイヤー**：「誰か乗っていないか確かめたいな。舟の中を覗き込んで、泥の足跡がないか周囲を探します」
> 
> **GM**：「舟の中に人はいないね。木箱は封が切られていない。だが、濡れた石段の上に、急いで駆け上がっていったような泥の足跡が奥へと続いている。急いでその足跡を追うなら、知力〈捜査〉か判断力〈生存〉で判定してみようか」

目に見えるものを確かめるだけなら、サイコロを振る必要はない。だが、時間に追われながら手がかりを拾うときや、危険を冒して何かを試みるとき、運命はサイコロに委ねられる。

難しく考える必要はない。「石段の泥を調べたい」「木箱の隙間にランタンの明かりをかざす」と、キャラクターがその場で行う動作を言葉にするだけで、物語は自然に動き始める。

たとえサイコロの目が振るわなくても、冒険がそこで終わるわけではない。足跡を見失って時間を浪費してしまったり、物音を立てて奥に潜む見張りに気づかれたりするかもしれない。だが、海側から回り込むか、武器を抜いて正面から突入するか、知恵を絞って別の抜け道を探すか――次の選択肢はいつだって目の前に開かれている。

## CH-01-depart 出発前の五つの確認

扉を開けて外へ出る前に、仲間と次の五つを確かめ合おう。

1. **今日の目的と帰る場所**：全員が「どこへ向かい、どこへ帰るのか」を言えるようにする。
2. **旅の荷物の分担**：明かり、食料、水、ロープ、手道具を誰が持っているか確認する。
3. **仲間を支える手段**：傷を癒やす手当てや呪文を誰が使えるか、残り回数を共有する。
4. **引き返す合図**：危険が迫ったとき、誰の声で撤退を決めるか合意しておく。
5. **心地よく遊ぶための約束**：楽しみたい場面や避けたい描写を伝え合う。セッションの途中でも休憩や描写の相談をしてよい。

最初の仕事を選ぼう。
港から船を出すなら、沖合のヴェイラ島で消えた灯台の火を確かめる依頼へ。港務官マレナが補給舟を用意して待っている。
内陸の街道を歩くなら、ハースウェル村の水車小屋へ。粉挽きの親方が、地下の水路から戻らない見習いの様子を見てきてくれる腕利きを探している。どちらも1レベルの冒険者にふさわしい旅立ちの仕事だ。

海と街道は、同じ広大なエスカロンの空の下へと繋がっている。あなたがこの旅で掴み取りたい願いを一つ胸に抱いて、一歩を踏み出そう。
