# 用語と略号

本書の略号と、旅の途中でよく出会う言葉をまとめた。基本ルールの入手先は[遊び方の案内](01-player-guide.md#CH-01-start)に、独自の能力の詳しい条件は各クラスの章にある。

## GLOSS-rules ルールの略号

| 表記 | 意味 | 読む場所 |
|---|---|---|
| AC | アーマー・クラス。攻撃ロールで命中を判定する際の基準 | 基本ルールの攻撃とアーマー・クラス |
| HP | ヒット・ポイント。現在値と最大値を区別する | 基本ルールのダメージと回復 |
| 一時的HP | HPとは別に得る防護。複数の獲得分を足し合わせない | [独自特徴の共通ルール](05-common-rules.md)と基本ルール |
| DC | 難易度。能力値判定やセーヴの目標値 | 特徴に指定されたDC。共通式は[共通ルール](05-common-rules.md) |
| PB | 習熟ボーナス | 使用している基本クラスの成長表 |
| リアクション | 指定された誘発に応じて使う行動。味方の特徴からの攻撃や移動でも、消費の指定を確認する | 基本ルールのリアクションと個々の特徴 |
| ft | フィート。戦闘用の地図では通常5ftを1マスとする | [共通ルール](05-common-rules.md) |
| GP・SP・CP | 金貨・銀貨・銅貨。1GP＝10SP＝100CP | 基本ルールの貨幣 |
| XP | 経験点。シナリオで成長の節目を使うか、経験点を使うかはGMと相談する | 基本ルールのレベル上昇 |
| 1d6、2d8 | 6面ダイス1個、8面ダイス2個を振る表記。複数個は出目を合計する | 基本ルールのダイスの振り方 |

## GLOSS-features 特徴を読むときの言葉

**バードの鼓舞。** バードが仲間を励ます基本クラス特徴。本書のバードのサブクラスも、その使用回数や鼓舞ダイスを用いる。[継史の楽派](subclasses/BRD-01.md)、[働き歌の楽派](subclasses/BRD-02.md)、[公議の楽派](subclasses/BRD-03.md)の各特徴を参照。

**野生の相。** ドルイドが獣へ姿を変える基本クラス特徴。本書には、この使用回数を別の効果へ使うサブクラスもある。[種石を育てる特徴](subclasses/DRU-01.md)と[共生の特徴](subclasses/DRU-02.md)を参照。

| 言葉 | 読み方 |
|---|---|
| クラス・レベル | そのクラスで得たレベル。複数クラスを持つ場合、合計のキャラクター・レベルと区別する |
| 自分の各ターンに1回 | 自分のターンで使える上限。他者のターンに同じ条件が生じても、この表記では使えない |
| 各ターンに1回 | 他者のターンも含め、各ターンごとの上限。実際に発動できる誘発と行動消費は別途満たす |
| 常時準備 | その呪文を常に準備しており、通常の準備数には数えない |
| 集中 | 持続する呪文などの維持条件。ダメージを受けたときのセーヴや終了条件は、基本ルールの集中の項にある |
| 味方 | 本書の独自特徴では、協力する同意あるクリーチャー。自分を含めるかは特徴に明記する |
| 強制移動 | 他の効果で移動させられる処理。通常の移動や瞬間移動と区別し、地形・経路の条件を確認する |
| 戦技ダイス | ウォーロードが戦技に用いる有限の資源。回復条件と消費の時点は[基本クラス章](classes/WLD.md)を参照 |
| 指揮の威風 | ウォーロードの指揮に関わる基準。[基本クラス章](classes/WLD.md)の選択と計算に従う |
| 放浪者の秘法 | サンドーナーが呪文スロットを使う独自の技。[基本クラス章](classes/SDN.md)で、通常の呪文発動との違いを確認する |

## GLOSS-world 世界の言葉

| 言葉 | 意味と参照 |
|---|---|
| 諸王冠と埋み火 | 本書の作品名。カタカナ表題は「クラウンズ・アンド・エンバーズ」 |
| 帰還の岸辺 | リターニング・ショアーズ。大嵐の後、人々が再び暮らしを築く内海沿岸を舞台とする本編の副題 |
| エスカロン | 本書の世界。暮らしと旅の入口は[プレイヤーガイド](01-player-guide.md) |
| ヴァルドラン暦842年 | 本書の基準年。歴史は[世界総覧](02-world.md) |
| 百冠 | 帝国崩壊後、多くの王国、公国、自由市などが並び立つ時代の呼び名 |
| ヴァルダ内海 | 人々が船で渡り、各地の港と文化を結ぶ海 |
| 灰燼の大嵐 | 779年に始まり、数十年にわたって内海一帯を襲った災害。沿岸の人々は内陸や外海へ逃れた |
| 帰還の時代 | 824年以降、海が静まり、外海と内陸から故郷へ戻る人々が増えた時代 |
| リーヴェン湾岸 | 第1部の主な冒険地域。北街道の村と城下町も含む。[地域ガイド](03-lieven-coast.md) |
| アルケイン | 百冠の時代を生き抜き、帝国の威風を継ぐ古都。アルケイン公国の中心。[世界総覧](02-world.md#CH-02-orsain) |
| ベルフォード | 人口約9,000人の開拓港湾都市であり自由市。宿、工房、市場、港が冒険の拠点になる。[都市ガイド](04-belford.md) |
| 王冠橋 | 湾口に巨大な橋脚が残る海上橋の遺構。市中の橋やオルデン橋とは別の場所 |
| オルデン橋 | 北の街道にある橋。ベルフォードから道のり14km |
| ハースウェル | ベルフォードから北街道を計22km進んだ村。水車と麦畑がある |
| 三本楡の宿場 | 北街道の宿場。〈牡鹿と大鍋亭〉で旅人が食事と仕事の話を交わす |
| ローデン | 北街道の城下町。ベルフォードから道のり44km |

地名の詳しい距離、旅程、宿泊先は[地域ガイド](03-lieven-coast.md)で確認できる。町や村で結んだ約束、その後に起きた変化は各卓の物語になる。
