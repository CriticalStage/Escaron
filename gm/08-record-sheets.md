# 旅と帰還の記録

旅で出会った人々、果たした約束、町に戻った灯火。冒険のあとに残ったことを書き留める。

## SHEET-adventure 冒険の記録

| 項目 | 記入欄 |
|---|---|
| 冒険名・ID、卓内の日付 | 　　　　　　　　　　　　　　　　　　　 |
| PCの名前と開始レベル | 　　　　　　　　　　　　　　　　　　　 |
| 今回引き受けた仕事 | 　　　　　　　　　　　　　　　　　　　 |
| 実際に達成したこと | 　　　　　　　　　　　　　　　　　　　 |
| まだ確かめていないこと | 　　　　　　　　　　　　　　　　　　　 |
| 次の旅で確かめたいこと | 　　　　　　　　　　　　　　　　　　　 |

## SHEET-return 帰還した町に残る四項目

| 項目 | 誰が・何が変わったか | 次に会う時の具体的な様子 |
|---|---|---|
| 人 | 　　　　　　　　　　　 | 　　　　　　　　　　　 |
| 場所 | 　　　　　　　　　　　 | 　　　　　　　　　　　 |
| 財産 | 　　　　　　　　　　　 | 　　　　　　　　　　　 |
| 合意 | 　　　　　　　　　　　 | 　　　　　　　　　　　 |

記入例：人「灯守イーラを救出」、場所「灯台と標識が稼働」、財産「船団は沖で待避し損失なし」、合意「島の小屋で休める」。次回は補給の荷を受け取るイーラを登場させる。
